# Spectra

Своя клиентская визуалка для Minecraft **1.21.4 (Fabric)**: кастомные модели, анимации, косметика и утилиты — одним модом.

## Сборка без ПК (прямо с телефона)

1. Создай репозиторий на github.com → **New repository** (название любое, например `spectra`).
2. **Add file → Upload files** — залей ВСЕ файлы из этого архива прямо из браузера телефона.
3. Открой вкладку **Actions** → сборка запустится сама после заливки.
4. Дождись зелёной галочки → открой сборку → внизу артефакт **spectra-jar** → скачай, внутри готовый `.jar`.
5. Закинь `.jar` в папку модов Zalith Launcher (версия 1.21.4 Fabric) и запускай.

Если сборка упала — открой лог сборки, найди строку со словом `error` и пришли мне, поправлю.
(Частая причина: версии в `gradle.properties` — Fabric API и Yarn обновляются, иногда надо поднять цифру.)

## Что уже внутри

- **`animation/`** — движок анимаций: ключевые кадры, easing (LINEAR, EASE_IN, EASE_OUT, EASE_IN_OUT, SINE), дорожки свойств, плеер.
- **`cosmetics/`** — система косметики: слоты (HEAD/BODY/BACK/HAND), ссылки на модель/текстуру, привязка анимаций.
- **`dev/ContentLoader`** — дев-плюшка: весь контент — JSON-файлы в `assets/spectra`. Кинул файл → нажал **F3+T** в игре → контент подхватился без рестарта.
- **`menu/SpectraScreen`** — меню визуалки, открывается на **V**. Показывает всё зарегистрированное. Это основа под будущие вкладки и превью.
- Примеры: `assets/spectra/animations/pulse.json`, `assets/spectra/cosmetics/sample_visor.json`.

## Как добавить свою анимацию

Создай `src/main/resources/assets/spectra/animations/<имя>.json`:

```json
{
  "id": "bounce",
  "duration": 30,
  "loop": true,
  "tracks": {
    "y": [
      { "time": 0, "value": 0, "easing": "EASE_OUT" },
      { "time": 15, "value": 1, "easing": "EASE_IN" },
      { "time": 30, "value": 0, "easing": "LINEAR" }
    ]
  }
}
```

Заливаешь на GitHub → Actions собирает → в игре анимация появляется в меню на V.
